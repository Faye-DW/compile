## 3. 实现细节

### 3.1 三地址码中间表示

中间代码以链表形式组织，每条指令为一个字符串，主要包括以下类型：

```
x := y op z       // 二元运算（算术/关系）
x := y            // 简单拷贝
x := #c           // 常量赋值
x := &y           // 取地址
x := *y           // 内存加载
*x := y           // 内存存储
x := CALL f       // 函数调用
IF x relop y GOTO L  // 条件跳转
GOTO L            // 无条件跳转
RETURN x          // 返回
ARG x             // 参数传递
READ x / WRITE x  // 内置 I/O
DEC x size        // 声明聚合类型变量
```

### 3.2 MIPS32 汇编生成

**主要流程**：

1. **解析 IR**：遍历三地址码链表，识别函数边界（`FUNCTION` 指令）
2. **变量收集**：分析参数、局部变量、临时变量，计算栈帧偏移
3. **栈帧布局**：
   - 参数通过 `$a0`–`$a3` 传递（超过4个的压栈）
   - 局部变量以 `$fp` 相对寻址
   - 函数序言保存 `$ra`、`$fp`，结尾恢复
4. **指令翻译**：将每条 TAC 直接映射到 MIPS 指令

**内置函数实现**：

- `read`：输出提示，读取整数，返回在 `$v0`
- `write`：输出整数和换行，返回 0

### 3.3 关键特性支持

| 特性       | 实现方式                                      |
| ---------- | --------------------------------------------- |
| 数组       | 计算元素偏移量：`base + index * elemSize`     |
| 结构体     | 编译时计算各字段偏移，通过 `base + offset` 访问 |
| 聚合拷贝   | 按字逐次拷贝（struct/array 赋值）             |
| 聚合传参   | 传递地址而非值                                 |
| 短路求值   | AND/OR 展开为条件跳转标签链                   |
| 函数声明   | 只生成声明对应符号的函数定义才输出完整代码     |

## 5. 实验总结

| 难点                       | 解决方案                                                  |
| -------------------------- | --------------------------------------------------------- |
| 数组/结构体的内存布局计算 | 在 IR 层面记录类型信息，编译时计算字段偏移和元素大小       |
| 聚合类型的赋值与传参       | 赋值时按字逐次拷贝；传参时传递地址指针                     |
| 短路求值的正确翻译         | AND/OR 展开为条件跳转标签链，保留短路语义                 |
| MIPS 调用约定              | 前4个参数用 `$a0`-`$a3`，其余压栈，使用 `$fp` 管理栈帧    |
