## 3. 实现细节

### 3.1 词法分析器（Flex）

**支持的 token 类别**：

- **关键字**：`int, float, struct, return, if, else, while`  
- **标识符**：字母/下划线开头，长度 ≤ 32，超长报错  
- **常量**：十进制、八进制（`0`开头）、十六进制（`0x/0X`）、浮点数（含科学计数法）  
- **运算符**：`=, >, <, >=, <=, ==, !=, +, -, *, /, &&, ||, !, .`  
- **分隔符**：`;, ,, (, ), [, ], {, }`

**错误处理示例**：

- 非法字符：`Error type A at Line X: Mysterious character 'c'.`  
- 非法八进制（如`089`）或十六进制（如`0x1g`）同样报错

### 3.2 语法分析器（Bison）

**文法关键规则**（精简）：

```
Program → ExtDefList
ExtDef → Specifier ExtDecList ; | Specifier ; | Specifier FunDec CompSt
Specifier → TYPE | StructSpecifier
VarDec → ID | VarDec [ INT ]
FunDec → ID ( VarList ) | ID ( )
Stmt → Exp ; | CompSt | return Exp ;
     | if ( Exp ) Stmt | if ( Exp ) Stmt else Stmt
     | while ( Exp ) Stmt
Exp → Exp = Exp | Exp && Exp | Exp || Exp | Exp RELOP Exp
     | Exp + Exp | Exp - Exp | Exp * Exp | Exp / Exp
     | ( Exp ) | - Exp | ! Exp
     | ID ( Args ) | ID ( ) | ID . ID | ID [ Exp ]
     | INT | FLOAT | ID
```

**优先级与结合性**（解决二义性）：

```bison
%right ASSIGNOP
%left OR
%left AND
%left RELOP
%left PLUS MINUS
%left STAR DIV
%right NOT UMINUS
%left DOT LB
%nonassoc LOWER_THAN_ELSE
%nonassoc ELSE
```

### 3.3 抽象语法树（AST）

**节点结构**：

```c
typedef struct ASTNode {
    char* type;        // 如 "Exp", "Stmt", "ID"
    char* value;       // 标识符名、常量值
    int line;
    struct ASTNode* left;
    struct ASTNode* right;
    struct ASTNode* child; // 用于多子节点链
} ASTNode;
```

**主要函数**：

- `ASTNode* createNode(char* type, char* value, int line)`  
- `void printAST(ASTNode* root, int level)`  
- `void freeAST(ASTNode* root)`

### 3.4 错误处理

- **词法错误**：在 Flex 中直接输出并继续  
- **语法错误**：`yyerror()` 报告 `Error type B at Line X: syntax error.`  
- **错误恢复**：使用 `error` 规则（如 `error ;`、`error }`）避免后续错误被淹没

## 5. 实验总结

| 难点                       | 解决方案                                              |
| -------------------------- | ----------------------------------------------------- |
| 多种数字格式识别与错误检测 | 正则匹配 + 额外语义检查                               |
